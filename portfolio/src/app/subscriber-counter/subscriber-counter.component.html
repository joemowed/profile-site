Subscriber Counter

Subscriber counter IOT device, using google firebase for backend services, and an ESP32 for device logic.

Figure 1: Counter Device

System architecture simplifys device requirements, the device only displays a number fetched from a database according to device ID. The value of the number depends only on configurations made to the easy to update web configurator. Being web based, adding new features (e.g. support for new social media platforms, a new premium subscription with faster update rate) is easy, and does not require an OTA update.
